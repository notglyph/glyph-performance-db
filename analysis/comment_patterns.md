# Comment Patterns

## Hidden-detail comment bait (strongest comment engine in the niche)

- **Hypothesis:** Content that hides a detail the audience must hunt (a riddle's flaw, an alibi hole) turns comments into the distribution engine — every hunting comment brings more hunters.
- **Supporting:** roblxify — 12+ pop-offs in ~19 days (Oct 2026), comment multiples up to ~182x (math puzzle, 5,644 comments — the largest comment-bait instance caught); feather-vs-steel riddle comments grew 156 → 1,585 in 24h. Second creator: craftee_films "LOVE LETTERS" (7.7x comments, genealogy debate).
- **Counterexamples:** Glyph's D.B. Cooper comment-mining (33 comments, mixed Top+Newest sample, Oct 18): no hidden detail to hunt, comment rate 0.22%, debate never fired — the absence case behaves as the hypothesis predicts.
- **Confidence:** Moderate.
- **Application to Glyph:** One frame in a dilemma can carry a findable detail (a number, a name patch, a background object) that the CTA points at — the debate gets a second engine.
- **Next test:** A Glyph upload with a deliberate hidden detail + spoken CTA; compare comment rate against the 0.22% no-detail baseline.

## Debate vs retention (Glyph)

- **Mom Dilemma** (74.8% stayed, below the retention bar) converted +366 subs on 1,237 comments — debate can substitute for retention as the growth engine.
- **Mind Reading** (82.7% stayed) won on retention with thin comments.
- **Comment-rate signal:** Mom ran ~1.6–1.8%; Escape Pod fired the channel's biggest debate at ~1.1% (3.7K comments) — so ~1%+ *with high absolute volume* is the working debate marker, not the older ~1.5% line. Both figures Calculated from Verified counts.
- **Loopholes:** Glyph comment samples keep surfacing viewer-invented loopholes ("grab both and jump", "finders keepers", secret-button cheats). Unclosed loopholes hijack the debate; the fix is closing the exact loophole visibly in-frame (standing script rule).
