# Hook Patterns — the first three seconds

The highest creative priority in this system. Only verified inspections count; uninspected videos are marked Unavailable, never reconstructed from titles.

## The stayed/avg-viewed split (Glyph, Verified ×2)

- **Observation:** When stayed% runs far below the channel's typical while average % viewed runs *above* typical, viewers who stay watch nearly everything — the loss is concentrated at the first-frame swipe. Theft Parachute: 58.1% stayed vs 91.5% avg viewed. D.B. Cooper (re-cut): 71.3% vs 101.4%. Studio's own headline on both: "more viewers swiped away."
- **Implication:** A weak body and a weak hook produce different signatures. Fix the frame, not the script, when the split appears.
- **Confidence:** Moderate (2 independent videos, same channel, consistent across 9 total reads — but reads of the same video are not independent examples).
- **Next test:** A Glyph upload whose first frame shows the full dilemma (both options + constraint visible) — does the split close?

## What the split can't tell us yet

- Neither failing video has a verified frame-by-frame first-3s breakdown logged from direct inspection. The D.B. Cooper re-cut changed the first 3 seconds and the swipe persisted — which specific frame element failed is **Unverified**. Logging verified first-frame descriptions for Glyph's own uploads (we have the files) is a standing gap this system should close.

## Competitor hook shapes (from tripwire breakdowns, public posts)

- **Named rarity / event framing** (nepshublox): the title itself promises a scarce drop ("Eternal Ghost Fish") — curiosity is pre-loaded before frame one.
- **Impossible-rule statement** (craftee_films): second-person quantified rules ("You Teleport Every Hour") make the viewer the subject; premise comprehension is instant.
- **Identity violation** (fearless.gman): a familiar person where they can't be ("My Dog is SMILING!") — dread in one frame.
- Each is a *shape*, logged from post-level inspection; full first-3s verification requires watching, and is marked per-video in `data/competitor_videos.jsonl`.
