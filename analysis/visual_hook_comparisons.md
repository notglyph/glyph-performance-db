## Comparison-format variance (MiAnimation1, metadata verified, visuals pending)

The same creator runs the same "Which X is Better?" comparison frame at wildly different outcomes (views vs the channel's recent-12 median of 582.5K, grid capture Oct 20, 2026):

| Video | Views | Multiple |
|---|---|---|
| "Which Dai Dai is Better?" | 3.2M | 5.5x breakout |
| "Which Haaland Sound is Better?" | 2.6M | 4.5x breakout |
| "Which song is better? Golden" | 1.2M | 2.1x notable |
| "Which Shakira Dai Dai is the Best?" | 303K | 0.52x underperformer |
| "Low IQ vs High IQ Building a Pyramids" (comparison frame) | 45K | 0.08x underperformer |

**Observation:** identical format, 0.08x–5.5x spread. The comparison *frame* is not the active ingredient — the specific pairing/topic is. This is a standing counterexample to any "format X wins" claim, including for Glyph's forced-choice dilemmas: the choice has to be one viewers actually split on.
